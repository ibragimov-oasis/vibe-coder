# Obsidian Copilot: Troubleshooting and FAQ

> **Источник:** `../new_repos/obsidian-copilot/docs/troubleshooting-and-faq.md`

## О чём

Типичные ошибки, проблемы с провайдерами, производительность, FAQ.

## Частые проблемы

| Проблема | Решение |
|---------|---------|
| API key error | Проверить ключ в настройках провайдера |
| Vault indexing slow | Исключить большие папки из индекса |
| Context too long | Включить auto-compact |
| Agent loop | Уменьшить max iterations |
