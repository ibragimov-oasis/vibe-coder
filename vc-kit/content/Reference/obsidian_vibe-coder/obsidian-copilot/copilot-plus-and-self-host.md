# Obsidian Copilot: Copilot Plus and Self-Host

> **Источник:** `../new_repos/obsidian-copilot/docs/copilot-plus-and-self-host.md`

## О чём

**Copilot Plus** — премиум-уровень с расширенными возможностями. **Self-Host Mode** — для запуска собственной инфраструктуры.

## Copilot Plus возможности

- ✅ Agent Mode (автономный агент)
- ✅ Projects (изолированные workspace)
- ✅ Advanced context engineering
- ✅ Web search

## Self-Host Mode

- Доступно для Lifetime/Believer подписчиков
- Собственный backend инфраструктура
- Полный контроль над данными
