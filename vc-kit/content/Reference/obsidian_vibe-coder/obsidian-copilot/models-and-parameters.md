# Obsidian Copilot: Models and Parameters

> **Источник:** `../new_repos/obsidian-copilot/docs/models-and-parameters.md`

## О чём

Управление chat-моделями, embedding-моделями и параметрами AI-поведения.

## Ключевые параметры

| Параметр | Описание |
|---------|----------|
| Temperature | Случайность ответов (0.0–2.0) |
| Max tokens | Максимальная длина ответа |
| Context window | Размер контекста |
| Top P | Nucleus sampling |

## Chat vs Embedding модели

- **Chat**: генерация ответов (GPT-4, Claude, Gemini)
- **Embedding**: векторный поиск vault (text-embedding-3)
