# Obsidian Copilot: Getting Started

> **Источник:** `../new_repos/obsidian-copilot/docs/getting-started.md`
> **Описание:** AI-плагин для Obsidian, интегрирующий LLM в workflow заметок.

## Что умеет Copilot for Obsidian

- Чат с AI прямо в vault
- Вопросы по содержимому vault (RAG)
- Кастомные команды над заметками
- Поиск в интернете
- Редактирование заметок через AI

## Быстрый старт

1. Установить плагин Copilot for Obsidian
2. Настроить LLM провайдер (API ключ)
3. Открыть чат (иконка в боковой панели)
