# Obsidian Copilot: LLM Providers

> **Источник:** `../new_repos/obsidian-copilot/docs/llm-providers.md`

## О чём

Настройка 16 встроенных AI-провайдеров Copilot for Obsidian. Поддерживает OpenAI-совместимые эндпоинты.

## Встроенные провайдеры (16)

- OpenAI, Anthropic Claude, Google Gemini
- Azure OpenAI, AWS Bedrock
- Mistral, Cohere, Groq
- Ollama (локальные модели)
- И другие

## Локальные модели

Через Ollama можно использовать:
```bash
ollama pull llama3
# Затем в Copilot: Base URL = http://localhost:11434
```
