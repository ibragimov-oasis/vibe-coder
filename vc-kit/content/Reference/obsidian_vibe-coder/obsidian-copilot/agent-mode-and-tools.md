# Obsidian Copilot: Agent Mode and Tools

> **Источник:** `../new_repos/obsidian-copilot/docs/agent-mode-and-tools.md`
> **Требование:** Copilot Plus лицензия.

## О чём

Автономный агент в Obsidian Copilot: reasoning step-by-step, выбор инструментов, выполнение задач без явных инструкций пользователя.

## Как работает

1. Пользователь задаёт цель
2. Агент разбивает на шаги
3. Выбирает нужные инструменты (vault search, web, edit)
4. Выполняет итеративно
5. Возвращает итог

## Инструменты агента

- Vault search & read
- Web search
- Note creation/editing
- Context mentions (@-mentions)
