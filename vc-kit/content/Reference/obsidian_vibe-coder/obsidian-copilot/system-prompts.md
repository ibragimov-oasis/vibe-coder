# Obsidian Copilot: System Prompts

> **Источник:** `../new_repos/obsidian-copilot/docs/system-prompts.md`

## О чём

System prompt — постоянная инструкция AI, формирующая его поведение во всех разговорах. Аналог "personality" или "role" для модели.

## Принцип

```
"You are an assistant that helps me with academic writing.
 Always cite sources. Respond in formal English."
```

## Области применения

- Задание тона и стиля ответов
- Ограничение области знаний
- Форматирование ответов
- Роль и persona
