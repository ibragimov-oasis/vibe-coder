## Категории компонентов

### 🔘 Кнопки и Actions
| Тип | Описание |
|-----|----------|
| Primary Button | Основное действие |
| Secondary Button | Второстепенное действие |
| Ghost Button | Прозрачная кнопка |
| Icon Button | Кнопка с иконкой |
| Loading Button | Кнопка с состоянием загрузки |
| Split Button | Кнопка с дропдауном |
