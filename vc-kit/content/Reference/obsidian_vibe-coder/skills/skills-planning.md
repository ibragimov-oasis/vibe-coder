# Skills: Planning (Matt Pocock)

> **Источник:** `../.claude/skills/skills-planning/`

## Навыки планирования

| Навык | Описание |
|-------|----------|
| `write-a-prd` | Написать полный PRD с требованиями |
| `prd-to-plan` | PRD → пошаговый план реализации |
| `prd-to-issues` | PRD → GitHub Issues с labels |
| `grill-me` | Серия вопросов для прояснения задачи |
| `design-an-interface` | Дизайн интерфейса по описанию |
| `request-refactor-plan` | Запрос структурированного плана рефакторинга |

## Использование

1. Запусти `grill-me` для прояснения требований
2. Используй `write-a-prd` для создания PRD
3. Конвертируй `prd-to-plan` → задачи
4. Или `prd-to-issues` → GitHub Issues
