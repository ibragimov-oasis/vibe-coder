# MCP: Nano-Banana (Image Generation)

> **Источник:** `../COMBINED/mcp-servers/mcp-nano-banana/`
> **CLI:** `npx -y nano-banana-2-mcp`
> **Требует:** `GEMINI_API_KEY`

## Описание

Генерация изображений через Google Gemini API. Используется для дизайн-задач и создания UI-прототипов.

## Применение

- Генерация UI wireframes
- Иллюстрации для документации
- Прототипирование дизайна

## Требования

```bash
export GEMINI_API_KEY="your-key"
npx -y nano-banana-2-mcp
```
