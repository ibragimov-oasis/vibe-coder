# How to Combine Repositories

> **Источник:** `../HOW_TO_COMBINE.md`
> **Тип:** Методологическое руководство по объединению репозиториев.

## О чём этот документ

Методология недеструктивного объединения репозиториев в монорепо:

1. Инвентаризация всех источников
2. Нормализация структуры директорий
3. Разрешение конфликтов имён
4. Создание индексных документов
5. Проверка целостности

## Принципы объединения

- **Не удалять** оригинальные файлы — только добавлять
- Создавать `README.md` в каждой директории
- Сохранять историю источника в frontmatter
