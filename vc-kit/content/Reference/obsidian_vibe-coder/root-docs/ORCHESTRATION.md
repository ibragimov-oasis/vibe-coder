# 📄 ORCHESTRATION — 5 Orchestration Systems Compared

> **Тип:** Mirror-заметка | **Источник:** `../ORCHESTRATION.md`
> **Краткое описание:** Сравнительный анализ 5 основных систем оркестрации: RuFlo, GSD, OMC, DeerFlow, Hermes.

## О документе

ORCHESTRATION.md сравнивает ключевые 5 оркестрационных систем первой волны. Помогает выбрать подходящую систему для задачи.

## Сравнение систем

| Система | Strengths | When to use |
|---------|-----------|-------------|
| **RuFlo** | 100+ агентов, Q-Learning Router, fault-tolerant | Сложные enterprise задачи |
| **GSD** | Context engineering, spec-driven, solves context rot | Разработка с PRD |
| **OMC** | 19 ролей, team pipeline, zero learning curve | Многоагентные команды |
| **DeerFlow** | LangGraph + FastAPI, deep research | Исследовательские задачи |
| **Hermes** | Self-learning, pattern extraction, skill creation | После каждой задачи |
