# Memory Setup Guide

> **Источник:** `../MEMORY_SETUP.md`
> **Тип:** Руководство по настройке трёх систем памяти Vibe-Coder v3.0.

## О чём этот документ

Пошаговая инструкция по настройке трёх систем памяти:

1. **Claude-Mem** — кратковременная память сессии
2. **Supermemory** — долгосрочная память между сессиями
3. **OpenViking** — контекст кодовой базы (ByteDance)

## Ключевые разделы

- Установка и конфигурация каждой системы
- Интеграция с MCP-серверами
- Команды проверки работоспособности
