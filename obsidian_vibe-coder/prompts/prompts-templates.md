Переиспользуемые шаблоны промптов для структурированного выполнения задач.

## Категории шаблонов

### Агентные промпты
- Системные промпты для мега-агентов
- Role-based prompts (19 ролей OMC)
- Специализированные задачи

### Task Prompts
- Code review шаблоны
- Debug investigation
- Security audit

### Planning Prompts
- PRD шаблоны
- Architecture review
- Sprint planning
