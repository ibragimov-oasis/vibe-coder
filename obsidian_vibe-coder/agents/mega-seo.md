```
IF SEO/meta/sitemap → mega-seo
```

## SEOMachine — 10 специализированных агентов

1. Keyword Researcher
2. Content Strategist
3. On-Page Optimizer
4. Technical SEO Auditor
5. Link Building Specialist
6. Local SEO Expert

## Интеграции

- **Google Analytics 4 (GA4)** — трафик, конверсии
- **Google Search Console (GSC)** — позиции, impressions
- **DataForSEO** — keyword data, SERP analysis
- **WordPress** — прямая публикация

```
1. Audit текущего состояния SEO
2. Keyword research (DataForSEO)
3. Контент-стратегия
4. On-page оптимизация
5. Technical SEO fixes
6. Отчёт (GA4/GSC данные)
```
