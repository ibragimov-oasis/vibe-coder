> **Мега-агент** для swarm координации и инфраструктуры.

## Когда использовать

```
IF infrastructure/swarm/scaling → mega-infrastructure
```

## Источники

RuFlo (80+ агентов) + **Squad** + **Multica**

## Squad (GitHub Copilot native)

Команды AI агентов в Copilot:
- Named agent casting — назначить роли участникам
- Watch mode — агенты мониторят изменения и реагируют
- Decisions archive — трекинг всех технических решений
- Agents learn from each other's work

```
Когда использовать Squad:
✅ Multi-file refactoring → cast: architect, coder, reviewer
✅ Feature development → cast: planner, coder, tester
✅ Code review → cast: reviewer, security-reviewer
```

- Multi-workspace support
- Agent platform
