# Awesome Obsidian

> **Источник:** `../new_repos/awesome-obsidian/`
> Кураторский список тем, плагинов и ресурсов для Obsidian.

## О чём

Curated список лучших плагинов, тем и ресурсов для Obsidian.md.

## Структура

- `README.md` — основной список
- `media/` — банер и скриншоты
- `code/css-snippets/` — CSS сниппеты

## Ключевые разделы

### Плагины (Plugins)
- Продуктивность: Tasks, Kanban, Calendar
- Ссылки: Graph Enhancer, Backlinks
- Интеграции: Git, GitHub
- AI: Copilot (Obsidian Copilot)
- Кодирование: Code blocks, syntax highlight
- Экспорт: PDF, HTML, Pandoc

### Темы (Themes)
- Minimal — чистый и быстрый
- Things — macOS-inspired
- Obsidian Nord — Nord color scheme
- Catppuccin — пастельная палитра
- AnuPpuccin — функциональная тема

### CSS Snippets
- Кастомные стили для элементов vault
- Snippets для графа, карточек, боковой панели

### External Tools
- Obsidian Publish
- Obsidian Sync
- GitHub интеграции

## Применение в vibe-coder vault

Для улучшения данного vault можно использовать:
- **Dataview** — SQL-подобные queries к заметкам
- **Templater** — мощные шаблоны с JavaScript
- **Kanban** — доска для задач
- **Copilot** — AI асистент прямо в vault
