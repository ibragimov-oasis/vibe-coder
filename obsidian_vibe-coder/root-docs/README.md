## О документе

README — главный документ репозитория. Рассказывает историю создания ULTRACAR: как студент-юрист из Японии без навыков программирования собрал 54 open-source репозитория в одну автономную AI-систему разработки.

Документ охватывает: архитектуру системы, числа (15 мега-агентов, 23 системы оркестрации, 3000+ навыков), расширенный пайплайн Step 0–4, дизайн-workflow, all 54 репозитория с описаниями.
