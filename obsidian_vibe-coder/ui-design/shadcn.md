# UI Design: shadcn/ui

> **Источник:** `../COMBINED/ui-design/ui-components-shadcn/`
> **Rule #3:** shadcn — второй в иерархии дизайна ULTRACAR.

## О чём

Customizable React components с полной accessibility поддержкой. Компоненты копируются в проект (не npm dependency), позволяя полную кастомизацию.

## Ключевые особенности

- ✅ Full accessibility (ARIA, keyboard navigation)
- ✅ Tailwind CSS основа
- ✅ Copy-paste в проект (не locked-in)
- ✅ TypeScript поддержка
- ✅ Dark mode из коробки

## Популярные компоненты

- Button, Input, Form, Select
- Dialog, Sheet, Popover
- Table, DataTable
- Tabs, Accordion, Collapsible
- Toast, Alert, Badge

## Установка

```bash
npx shadcn@latest add button
npx shadcn@latest add form
```
