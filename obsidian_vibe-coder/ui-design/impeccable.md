# UI Design: Impeccable (Anti-Slop)

> **Источник:** `../COMBINED/ui-design/ui-impeccable/`
> **Rule #3:** Impeccable — третий в иерархии дизайна ULTRACAR.

## О чём

**Anti-slop detection** система + 18 команд для устранения generic AI-дизайна. 7 reference guides.

## 18 Дизайн-команд

```
/improve      → улучшить существующий дизайн
/audit        → аудит на anti-patterns
/refine       → тонкая настройка деталей
/elevate      → поднять визуальный уровень
/simplify     → упростить без потери смысла
/brand        → применить brand guidelines
/accessibility → проверка доступности
/contrast     → проверка контраста
/spacing      → оптимизировать пространство
/typography   → улучшить типографику
/hierarchy    → выстроить иерархию
/motion       → добавить micro-interactions
/dark-mode    → оптимизировать для dark mode
/mobile       → оптимизировать для мобильных
/density      → настроить информационную плотность
/color        → улучшить цветовую схему
/grid         → оптимизировать сетку
/components   → компонентный аудит
```

## Anti-Pattern Detection

Impeccable обнаруживает и исправляет:
- Generic "AI-look" (слишком perfect, безликий)
- Inconsistent spacing
- Poor visual hierarchy
- Accessibility violations
