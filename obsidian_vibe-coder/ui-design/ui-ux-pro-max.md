# UI Design: UI/UX Pro Max (161 Rules)

> **Источник:** `../COMBINED/ui-design/ui-rules/ui-ux-pro-max/`
> **Rule #3:** UI/UX Pro Max — шестой (финальный) в иерархии дизайна ULTRACAR.
> **Применяется к ЛЮБОМУ дизайн-выводу.**

## О чём

**161 правило рассуждения** + **67 стилей** для любого UI-вывода.

## Структура

- `docs/` — документация правил
- `cli/` — CLI инструменты для применения
- `data/` — данные и конфигурации
- `src/` — исходный код

## Ключевые правила (примеры)

- R001: Иерархия важности (primary > secondary > tertiary)
- R012: Whitespace как дизайн-элемент
- R025: Contrast ratio ≥ 4.5:1 (WCAG AA)
- R034: Touch targets ≥ 44×44 pt
- R067: Loading state для любого async действия
- R089: Error messages — конкретные и actionable
- R120: Micro-interactions — немедленный feedback

## 67 Стилей

От Minimal Clean до Rich Expressive — полный спектр дизайн-стилей.
