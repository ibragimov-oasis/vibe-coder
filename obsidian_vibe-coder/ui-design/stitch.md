# UI Design: Stitch (Google Stitch)

> **Источник:** `../COMBINED/ui-design/ui-stitch-skills/`
> **Rule #3:** Stitch — пятый в иерархии дизайна ULTRACAR.

## О чём

Google Stitch — AI-driven design generation. Генерирует React компоненты из описания + синтезирует DESIGN.md.

## Возможности

- **Design generation** — создание UI из текстового описания
- **React components** — готовый код компонентов
- **DESIGN.md synthesis** — документация дизайн-решений
- **Figma-compatible** — экспорт в дизайн-инструменты

## Применение

```
"Create a dashboard card showing monthly revenue with sparkline"
→ Stitch generates:
  - React component code
  - DESIGN.md with design decisions
  - Tailwind classes
```
