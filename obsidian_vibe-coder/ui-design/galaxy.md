# UI Design: Galaxy (3000+ Components)

> **Источник:** `../COMBINED/ui-design/ui-components-galaxy/`
> **Rule #3:** Galaxy — первый в иерархии дизайна ULTRACAR.

## О чём

3000+ уникальных UI-элементов. Самая большая коллекция компонентов в ULTRACAR.

## Категории компонентов

| Категория | Примеры |
|-----------|---------|
| **Buttons** | Primary, Secondary, Ghost, Icon, FAB |
| **Cards** | Product, Profile, Stat, Feature |
| **Forms** | Login, Registration, Search, Filter |
| **Inputs** | Text, Select, Checkbox, Radio, Slider |
| **Notifications** | Toast, Alert, Badge, Banner |
| **Patterns** | Navigation, Sidebar, Dashboard, Layout |
| **Checkboxes** | Toggle, Indeterminate |
| **Toggle-switches** | On/Off, Multi-state |
| **Tooltips** | Hover, Click, Contextual |
| **Loaders** | Spinner, Skeleton, Progress |
| **Radio-buttons** | Group, Card-radio |

## Workflow

```
1. Проверь Galaxy ПЕРВЫМ (3000+ компонентов)
2. Если не нашёл → shadcn/ui
3. Если не нашёл → Stitch generation
4. Если не нашёл → Custom build
```
