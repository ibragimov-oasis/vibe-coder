# ✏️ Skill: edit-article

> **Что делает:** Редактирует технические статьи, документацию и README с сохранением смысла.
> **Автор:** Matt Pocock | **Агент:** [[agents/mega-writer]]

## Назначение

`edit-article` — навык улучшения технического текста:
- Улучшает ясность и читаемость
- Исправляет структуру и flow
- Сохраняет оригинальный голос и смысл
- Не добавляет лишнего

## Принципы редактирования

### Что улучшаем
- **Ясность:** каждое предложение — одна мысль
- **Структура:** логический поток от проблемы к решению
- **Конкретность:** примеры > абстракции
- **Краткость:** убрать слова-паразиты

### Что НЕ делаем
- ❌ Изменяем технический смысл
- ❌ Добавляем непроверенные утверждения
- ❌ Меняем code examples без понимания
- ❌ "Улучшаем" то, что работает

## Workflow

```
Input:  Черновик статьи/документа
         ↓
edit-article:
  1. Pass 1: Структура (разделы, заголовки)
  2. Pass 2: Ясность (каждый абзац)
  3. Pass 3: Краткость (убрать лишнее)
  4. Pass 4: Финальная проверка
         ↓
Output: Улучшенная версия с track changes
```

## Чеклист редактора

- [ ] Заголовок отражает суть?
- [ ] Введение отвечает: "зачем читать дальше"?
- [ ] Каждый раздел — одна идея?
- [ ] Примеры есть?
- [ ] Заключение даёт action item?
- [ ] Нет жаргона без объяснения?
