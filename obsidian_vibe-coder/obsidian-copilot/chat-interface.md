# Obsidian Copilot: Chat Interface

> **Источник:** `../new_repos/obsidian-copilot/docs/chat-interface.md`

## О чём

Основной интерфейс взаимодействия с AI в Obsidian: режимы чата, управление сообщениями, история, настройки, auto-compact.

## Режимы

- **Chat** — обычный разговор с AI
- **Vault QA** — вопросы по содержимому vault
- **Agent Mode** — автономное выполнение задач

## Ключевые возможности

- История чатов
- Auto-compact (сжатие длинных контекстов)
- Управление сообщениями (edit, delete, regenerate)
