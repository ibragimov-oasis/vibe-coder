# MCP: GitNexus (Code Map)

> **Источник:** `../COMBINED/mcp-servers/mcp-gitnexus/`
> **CLI:** `npx -y gitnexus@latest mcp`

## Описание

Карта и анализ кодовой базы. Используй перед любой задачей с кодом для понимания структуры проекта.

## Ключевые команды

```bash
mcp gitnexus map        # карта кодовой базы
mcp gitnexus analyze    # анализ структуры
mcp gitnexus search     # поиск по символам
```

## Применение

- Понять структуру перед изменением кода
- Найти зависимости между модулями
- Навигация по большим кодовым базам
