# Orchestration: Vibe-Kanban

> **Источник:** `../COMBINED/orchestration/core-vibe-kanban/`

## Описание

Kanban-board управление задачами. **Объединён с Task Master** — Task Master расширяет Vibe-Kanban MCP-based AI task management.

## Концепция

Визуальное kanban-управление задачами в разработке:
- Колонки: Todo → In Progress → Review → Done
- AI-интеграция через Task Master

## Связь с Task Master

Vibe-Kanban + Task Master = единая система управления задачами с MCP-инструментами.
