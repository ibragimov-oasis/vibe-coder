# Orchestration: PraisonAI

> **Источник:** `../COMBINED/orchestration/core-praisonai/`

## Описание

Multi-agent framework с поддержкой 100+ LLM провайдеров. Режимы: route, parallel, loop, repeat. Guardrails и MCP-интеграция.

## Режимы выполнения

| Режим | Описание |
|-------|----------|
| `route` | Маршрутизация к нужному агенту |
| `parallel` | Параллельное выполнение |
| `loop` | Цикличное выполнение |
| `repeat` | Повторение N раз |

## Ключевые возможности

- 100+ LLM провайдеров (OpenAI, Anthropic, local)
- Guardrails — ограничения безопасности
- MCP интеграция
